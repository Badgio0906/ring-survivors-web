# Ring Survivors — Web版

[ブラウザで遊ぶ](https://badgio0906.github.io/ring-survivors-web/)

ゲーム v0.9.1 / Web web-v1。PCブラウザ向け試作です。初回は約79MBのデータを読み込みます。

- 最初に画面をクリックして開始。
- WASD／矢印／スティックで移動、攻撃は自動。
- Enter・Space／×で決定、Esc／○で戻る。戦闘中はEsc／Optionsでポーズ。
- セーブは端末・ブラウザごとに保存。Windows版との共有はありません。
- AI分析データは結果・統計画面からコピーできます。コピーが拒否された場合は全文欄からコピーしてください。
- スマホ専用のタッチ操作は未実装です。

Godot 4.5.1、WebGL2、単一スレッド。高密度戦闘では処理落ちする場合があります。実機コントローラーのブラウザ別動作、Edge/Firefoxは未検証です。

このリポジトリはWeb配布ファイルのみです。開発用ソース、セーブ、ランログは含みません。
