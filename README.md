# Ring Survivors — Web版（スマホ操作対応）

[ブラウザで遊ぶ](https://badgio0906.github.io/ring-survivors-web/)

ゲーム v0.9.1 / Web web-mobile-v1。PCとスマホのブラウザ向け試作です。初回は約79MBのデータを読み込みます。

スマホでは横向き推奨。左下の仮想スティックで移動、剣・スキルは自動です。右上から一時停止できます。装備・階層・強化・覚醒・報酬は大きなタッチ用ボタンで選択します。メニューはスクロールできます。

PCではWASD／矢印／スティックで移動、Enter・Space／×で決定、Esc／○で戻る。戦闘中はEsc／Optionsでポーズ。

セーブは端末・ブラウザごとに保存。Windows版との共有はありません。AI分析データは結果・統計画面からコピーできます。コピーが拒否された場合は「全文を選択」から手動コピーしてください。

Godot 4.5.1、WebGL2、単一スレッド。高密度戦闘では処理落ちする場合があります。スマホの実機性能、全画面やクリップボードのブラウザ別挙動は未検証です。

このリポジトリはWeb配布ファイルのみです。開発用ソース、セーブ、ランログは含みません。
